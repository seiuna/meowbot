# LOLBins 攻击手法与防御

## 攻击手法
1. 先安装合法应用（如 Python、Node.js、7-Zip）—— 杀毒软件认签名，不会拦截
2. 创建计划任务，以 SYSTEM 权限运行
3. 计划任务调用 powershell 从网络下载恶意代码并在内存中执行
4. 无文件落地，传统特征码扫描完全无效

## 为什么难查杀
- **白名单绕过**：合法签名软件放行
- **SYSTEM 权限**：安全产品常放行系统进程的网络请求
- **分离加载**：通过合法程序执行恶意逻辑
- **无文件攻击**：没有恶意 exe 落盘

## 防御措施
1. 开启 Windows 4688 进程创建审计 + 命令行日志
2. Windows Defender ASR 规则：
   - 阻断计划任务派生的 PS 执行不受信任代码
   - 阻断混淆/加密的 PS 脚本
   - 阻断计划任务进程访问网络
3. AppLocker / WDAC：白名单策略，只允许签名程序运行
4. 网络出站控制：防火墙 + EDR 监控异常外连
5. Sysmon 监控计划任务变更（Event ID 4698 / 4699）
6. 最小权限原则：限制用户创建计划任务权限，主机走代理上网

## 总结
单一杀毒软件防不住，需要 EDR + NTA + 日志审计三层配合
